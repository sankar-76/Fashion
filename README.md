# Veilhaus - Luxury Fashion E-Commerce

## 📋 Overview

Veilhaus is a modern, luxury fashion e-commerce website built with React.js. The platform showcases a curated collection of premium clothing with a focus on quiet luxury, intentional design, and sustainable fashion. The website features smooth animations, responsive design, and an elegant user interface.

## ✨ Features

### 🏠 Home Page
- Hero section with parallax scrolling effect
- Animated entrance animations using GSAP
- Marquee ticker showcasing brand philosophy
- Featured products grid with hover effects
- Statistics section highlighting brand achievements
- Editorial section with brand manifesto
- Newsletter subscription form

### 👕 Collection Page
- Product grid layout with 28+ fashion items
- Filter system by category (Outerwear, Evening, Essentials, Knitwear, Tailoring)
- Responsive product cards with images
- Season badges (AW/SS)
- Quick add to bag functionality
- Price display in INR (₹)
- Smooth filter animations

### 📞 Contact Page
- Fully functional contact form with validation
- Topic selection buttons
- Contact information cards
- Social media links
- Interactive map location
- Business hours display
- Success message on form submission

### 🎨 Design Features
- Custom Tailwind CSS styling
- Responsive design for all devices
- GSAP scroll-triggered animations
- Framer Motion interactions
- Backdrop blur effects
- Gradient text effects
- Custom font families (Display, Body, Mono)

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| React.js | Frontend framework |
| Tailwind CSS | Styling and responsive design |
| GSAP | Advanced scroll animations |
| Framer Motion | Component animations |
| React Router DOM | Navigation and routing |
| Pexels API | High-quality product images |
